# Yuexi Wild Dog Milk

粤西野生狗奶是一个 Minecraft Fabric 1.21.1 娱乐模组。

## 当前功能

- 潜行后用空桶对成年狼挤狗奶
- 制作并饮用粤西野生狗奶
- 合成百年陈酿野生狗奶，永久解锁终极时间能力“沧海桑田”
- 永久保质期能力
- 全局时间流速切换：20、100、200、500、1000、2000、5000 与 9999 TPS
- V 循环时间流速，Ctrl + V 切换极限时间，Shift + V 执行紧急时间复位
- B 时间暂停：世界逻辑停在时间中，玩家仍可移动和观察
- G 岁月如梭：使用原版 Tick Sprint 让世界快速经历完整一天
- H 沧海桑田：使用原版 Tick Sprint 尽可能快速执行十个 Minecraft 日的世界逻辑
- 左上角时间 HUD 与暂停反馈
- 生物加速衰老与寿命耗尽

### 特殊生物时间老化

时间流速加快后，不同生物会以不同方式迎来保质期：僵尸会腐烂成骷髅，骷髅会风化为骨粉，史莱姆会逐渐缩小并蒸发，末影人会从时间线中裂解，烈焰人会燃尽，雪傀儡会融化。末影龙与凋零默认不参与普通寿命系统。

### 自然时间加速

提高时间流速后，原版正在随机刻的区块会获得额外的随机刻预算，因此植物生长、树苗成树、甘蔗、竹子、下界疣及其他随机刻世界变化都会明显加速。模组不会修改玩家设置的 `randomTickSpeed`；若该规则为 `0`，自然随机刻仍保持关闭。

### Boss 寿命

末影龙和凋零拥有远高于普通生物的独立寿命。它们只会在时间加速、岁月如梭或沧海桑田时老去，并显示独立的剩余寿命条；需要利用极端时间能力才能将它们熬死，同时保留原版的死亡与掉落结果。

### 百年陈酿野生狗奶

百年陈酿野生狗奶是终局版本的野生狗奶，饮用后会同时获得永久保质期，并永久解锁“沧海桑田”。

- G：岁月如梭，快速执行一个 Minecraft 日（24000 Tick）
- H：沧海桑田，快速执行十个 Minecraft 日（240000 Tick）

沧海桑田使用 Minecraft 原版 Tick Sprint，尽可能快速执行十天的完整世界逻辑。实际完成速度取决于硬件、已加载区块、实体数量、红石机器和当前世界负载。

## 环境

- Minecraft: 1.21.1
- Loader: Fabric
- Java: 21

项目目前仍处于早期开发阶段。

极高 Tick Rate 会显著提高 CPU 负载。9999 TPS 是目标 Tick Rate；实际能否达到取决于电脑性能和世界复杂度，并不保证始终达到该速度。

## 过量饮用

连续饮用过多野生狗奶会累积“时间负荷”。负荷过高后，玩家自身的时间线会发生错位，严重时可能突然回到数秒前的位置。时间负荷按照现实时间逐渐恢复，因此提高世界 Tick Rate 无法快速消除副作用。

当前的狗奶桶和粤西野生狗奶使用原版材质占位，后续可替换为正式贴图。
