# Yuexi Wild Dog Milk

粤西野生狗奶是一个 Minecraft Fabric 1.21.1 娱乐模组。

## 当前功能

- 潜行后用空桶对成年狼挤狗奶
- 制作并饮用粤西野生狗奶
- 永久保质期能力
- 全局时间流速切换：20、100、200、500、1000、2000、5000 与 9999 TPS
- V 循环时间流速，Ctrl + V 切换极限时间，Shift + V 执行紧急时间复位
- B 时间暂停：世界逻辑停在时间中，玩家仍可移动和观察
- G 岁月如梭：使用原版 Tick Sprint 让世界快速经历完整一天
- 左上角时间 HUD 与暂停反馈
- 生物加速衰老与寿命耗尽

## 环境

- Minecraft: 1.21.1
- Loader: Fabric
- Java: 21

项目目前仍处于早期开发阶段。

极高 Tick Rate 会显著提高 CPU 负载。9999 TPS 是目标 Tick Rate；实际能否达到取决于电脑性能和世界复杂度，并不保证始终达到该速度。
